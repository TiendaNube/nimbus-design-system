# Changelog

The Breadcrumb component shows the user's position in a multi-level navigation hierarchy and lets them navigate back to any ancestor level.

## 2026-09-30 `1.0.0`

#### 🎉 New features

- Added the `Breadcrumb` component with width-driven collapse, an overflow panel for hidden ancestors, router-aware links through `as` and `linkProps`, and keyboard focus management. ([#553](https://github.com/TiendaNube/nimbus-design-system/issues/553) by [@prescillahurbin-tiendanube](https://github.com/prescillahurbin-tiendanube))
