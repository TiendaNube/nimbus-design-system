# Changelog

The Breadcrumb component shows the path from the root to the current page and collapses long paths into a hidden-levels panel.

## 2026-10-06 `1.0.0`

#### 🎉 New features

- Breadcrumb: Adds the new `Breadcrumb` composite component, with `items`, `maxVisible`, `linkAs`, `ariaLabel` and `hiddenLevelsLabel` properties. ([#553](https://github.com/TiendaNube/nimbus-design-system/issues/553))
