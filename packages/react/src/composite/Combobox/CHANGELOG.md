# Changelog

The Combobox component lets a person choose one value, or several, from a list of options by typing to filter it, with optional instant creation, enriched options and hierarchies of up to six levels.

## 2026-11-13 `1.0.0`

#### 🎉 New features

- Initial release of the Combobox component: single and multiple selection with chips, filtering by label that ignores case and diacritics, instant creation through `onCreate`, enriched options with subtitle and tag, disabled options, hierarchies of up to six levels with back control, selectable parents and whole-tree search, clearing and clear all, hidden form values and `required` validity, controlled and uncontrolled value, translatable `labels`, `appearance`, keyboard map and ARIA combobox semantics. ([#636](https://github.com/TiendaNube/nimbus-design-system/pull/636) by [@claude](https://github.com/apps/claude))
