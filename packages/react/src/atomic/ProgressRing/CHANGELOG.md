# Changelog

The ProgressRing component displays measurable, determinate progress as a circular ring, with a visible, programmatically exposed value.

## 2026-09-10 `1.0.0`

#### 🎉 New features

- Initial release: `value` (0–100, clamped), `size` (`small`/`medium`/`large`/number), and a required `aria-label`. Implements AC-01–AC-04 of the approved candidate spec for issue #533. Visual/token contract (stroke width, track visibility, color/appearance) is intentionally not yet defined — see the component's README.
