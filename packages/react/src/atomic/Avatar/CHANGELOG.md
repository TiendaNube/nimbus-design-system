# Changelog

The Avatar component shows the identity of a store, a person or an AI assistant with an initial or an icon inside a circle.

## 2026-11-24 `1.0.0`

#### 🎉 New features

- Initial release of the Avatar component: a circle with an initial or an icon, `small` (20px), `medium` (24px) and `large` (40px) sizes, `neutral` and `ai` appearances, decorative by default with an optional accessible name (`aria-label` or `aria-labelledby`), not focusable, and `Avatar.Skeleton`, which keeps its size inside a narrow flex row. Sizes and colors come from the `components.avatar` theme values, so it follows the current themes and Norte UI. ([#674](https://github.com/TiendaNube/nimbus-design-system/pull/674) by [@noecondoleo](https://github.com/noecondoleo))
